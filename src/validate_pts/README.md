# 独立核验窗口

运行（仓库根目录，`sar-water` 环境）：

```powershell
python src/validate_pts/main.py
```

依赖 `tkinter`、Pillow、Rasterio、Fiona、PyProj、Shapely、NumPy。当前 sar-water 已安装，不依赖 QGIS、Qt 或网页服务器。

## 核验流程

1. 默认打开密云的 `manual_review.gpkg`，也可点击“打开核验GPKG”。使用之前汇总脚本生成的统一核验点格式。
2. 选择场景和“未核验 / 全部 / 无法确定 / 已确定”。点击点位，地图自动定位；黄色圆圈的中心是核验像元中心，不是水体边界。
3. 添加带坐标系的本地光学 GeoTIFF/VRT，选择 RGB 波段（普通RGB通常为1,2,3，具体以文件波段说明为准）。单波段自动灰度显示。可加载多个文件并切换，程序不会按文件名猜拍摄日期。
4. 或切换“天地图”，填写自己的 Key 后点击“应用 / 刷新”。仅请求当前视窗，重复浏览复用瓦片缓存。Key仅在本次内存中使用，不写入配置、成果或错误信息；也可从 `TIANDITU_TOKEN` 环境变量读取。
5. 填写参考资料、参考影像日期、核验人、置信度和备注，点击“1 水体 / 0 非水体 / U 无法确定”。默认保存后下一点；点位切换或关闭窗口时，已编辑的备注会自动保存。
6. 点击“撤销上次保存”可恢复上一个保存动作；“清空参考类别”恢复为未核验。再次打开同一个GPKG即可继续未完成点。
7. 完成人工核验后，使用 `scripts/evaluate_threshold_review.py` 的 `MODE='evaluate'` 计算加权精度。无需从CSV回导。

鼠标滚轮缩放，按住鼠标拖动后松开平移。“定位点”回到当前点。地图或列表获得焦点时，快捷键 `1 / 0 / U` 保存类别，左右方向键切换点；输入文本时快捷键不生效。

## 参考影像与保存

- GeoTIFF按当前视窗读取并重投影到Web Mercator，不整景载入、不修改原文件。P2–P98仅为显示拉伸；关闭时按0–255显示，主要适合8位RGB成品。未覆盖区域为深灰色。
- 本地光学与SAR应核对拍摄时间及配准。天地图默认影像底图日期未知，不能直接认定为2025年7月/8月的真值；时相不符或无法确定时标记`-1`并备注。
- 默认隐藏算法预测，建议先独立判读，再按需显示预测类别，避免按照模型结果填答案。
- 修改直接写回GPKG中的人工字段；点位坐标、ID、预测、分层、权重不改变。首次保存会生成 `manual_review.before_gui.gpkg` 备份，后续不覆盖备份。
- `manual_review.viewer.json` 仅记录核验人、影像列表和显示设置，不保存Key。参考日期写入已有`reference`字段，格式为`资料名称 | 影像日期=YYYY-MM-DD`；`review_date`是实际核验时间。
- `src/validate_pts/main.py` 顶部集中设置默认核验文件、瓦片缓存位置和初始缩放级别。不要同时用另一个程序编辑同一核验文件。

天地图使用 `img_w` WMTS影像服务。需申请有相应服务权限的Key；若瓦片请求失败，窗口会提示失败数量，失败响应不会被缓存。获取方式见：https://lbs.tianditu.gov.cn/server/MapService.html 。
