# 洪水遥感水体提取成果质量核验规范

**项目试行稿 v1.0　｜　2026-11-21**

本规范供制图人员、独立核验人员和成果签发人使用。适用于模型提取、阈值分割、人工勾绘及人工精修的水体面矢量和栅格，按景、按日期或按事件执行。核验记录应能回答四个问题：影像看到了哪里，水体在哪里被误报或漏报，岸线偏了多少，哪些结论仍缺证据。

## 1　确定核验对象

| 产品 | 判读口径 | 报告必须注明 |
| --- | --- | --- |
| 过境时水体 | 在影像获取时刻可确认的地表水，包括河流和水库原有水面 | 过境时间、时区、有效覆盖范围，对植被或建筑遮挡区的处理 |
| 本次新增淹没 | 灾前为陆地、灾中有水，并有证据支持变化与本次事件有关 | 灾前和灾中时刻、灾前基准来源。灌溉、季节性涨水或水库调度可能解释变化时，标为归因待核 |
| 事件期间观测到的最大范围 | 规定时段内，各次观测确认的淹没范围取空间并集 | 起止时间、观测次数、缺测时段。只有观测覆盖洪峰或另有证据时，才可进一步解释为洪峰范围 |

任务负责人在抽样前填写附表 A，确定感兴趣区（ROI）、待验版本、产品类型、统计单位和验收门槛。参考影像允许时差、最小制图面积和岸线容差应与洪水涨退速度、输入分辨率及成果用途相符。正式验收采用任务书或双方事先约定的数值；缺少数值约定时，报告实测结果及限制，保留“未判定达标”状态。国内业务可对照水利行业标准 SL/T 750.5—2025；本文件中的抽样及放行规则为项目试行约定。[全国标准信息公共服务平台](https://std.samr.gov.cn/hb/search/stdHBDetailedCNF?id=515ABB1A8E05C04FE06397BE0A0AC508)

## 2　应急快报发布前逐景检查

由制图人员自查，复核人查看原始影像和最终成果。无同期参考资料时仍应完成以下检查。可以发布标明覆盖和局限的快报，精度栏填写“尚未独立核验”。检查项目参考了 Copernicus 对交付完整性、矢量拓扑、专题精度和位置精度的区分。[Copernicus 成果质量检查](https://mapping.emergency.copernicus.eu/about/risk-and-recovery-manual/service-overview/quality-controls/)

| 检查项 | 怎么查 | 记录什么 |
| --- | --- | --- |
| 来源与时相 | 核对影像编号、过境时刻和传感器。SAR 同时核对极化、幅度或功率、地理编码版本及其与算法输入的匹配情况。人工成果注明所用底图、影像日期和修订来源 | 影像列表、成果版本、配置或人工编辑记录 |
| 覆盖与未知 | 在 ROI 内分别统计已覆盖、有效可判读、已覆盖但无法判读、未覆盖面积。有效覆盖率为可判读面积除以 ROI 面积。同日多景先做空间去重，重叠区结果冲突时记录取用规则及时间 | 面积（km²）、有效覆盖率、缺测图层。不得把无覆盖、NoData 或无法判读区写成干地 |
| 空间对齐 | 核对坐标系、像元大小和网格原点。选取分布在疑点附近及场景不同位置的稳定地物，检查参考影像与 SAR 的相对偏移。避开水边、阴影边缘及高建筑物顶部 | 核查点、偏移方向和距离（m）。偏移足以影响待验岸线时，先复核配准再量边界 |
| 提取与修订 | 同屏查看原始影像、初提、最终水体及实际生效的掩膜；人工勾绘则比较底图、初稿与修订稿。检查原始候选被删和非水体被保留两类位置 | 位置、发生变化的环节、影响对象和局部对照图 |
| 最终文件 | 打开栅格和面矢量，核对类别、NoData、范围、孔洞和几何有效性。由栅格转面的成果叠回原网格，检查遗漏、接缝与面积差；做过平滑、简化或最小面积筛选时注明差异来源 | 检查结果、差异面积及原因。只有人工矢量时记录量面积的投影或测地方法 |

**重点地物应定向复查。** 山谷暗斑查地形阴影或叠掩，库湾缺口查候选是否被掩膜删除，道路暗带查真实积水与路面混淆，农田查灌溉和季节性水面，居民区及植被区查水体漏报。行政道路数据与水面相交、候选位于陡坡、与历史水体不一致，都只触发复查。记录每个疑点的坐标、证据和处置，疑点清单单独保存。

## 3　正式核验的取样和人工判读

1. **冻结成果与范围。** 保存待验成果版本、有效域、抽样底表和随机种子。模型、阈值和人工成果做对照时，使用同一参考资料、同一批点和共同有效域；另报各自缺测面积。按日期验收合并图时，在去重后的日期产品上建立抽样框。逐景抽样汇总按“景次”解释。
2. **覆盖误报和漏报。** 在有效域内按初定水体内部、岸线缓冲带、其余非水体三个互斥区域分层随机抽样。第三层应覆盖可能整块漏掉的洪泛区。定样前记录各层像元总数、计划样本数、缓冲宽度及入样概率。水体稀少或重点地类可增设层，分层后仍应覆盖整个目标总体。点数按拟报告指标、容许误差及预判错误率确定，先小范围试判，再冻结正式方案。灾区投诉点、Agent 推荐点和定向检查点另表登记。[Copernicus 洪水制图实例 EMSN068，技术报告第 6.1 节](https://mapping.emergency.copernicus.eu/activations/EMSN068/)
3. **独立判读。** 首轮隐藏待验类别、制图人员意见和 Agent 建议。记录参考资料编号、采集时刻、与 SAR 的时差、配准情况和判读人。优先使用同一水情阶段的独立影像、无人机影像或定位现场记录。水位站用于核对涨退过程，事后洪痕用于佐证事件期间曾受淹。仅有同幅 SAR 的二次解译时，报告“同源判读一致性”。日期不明的在线底图仅用于定位。
4. **按问题分别赋值。** 当时水体和灾前水体各记“有水、无水、无法确定、未判读”；对于新增淹没，另记事件归因依据。灾中水面清晰、灾前未知时，可确认当时有水，新增淹没仍待核。点代表的像元或地面单元及混合像元规则应提前约定，同一批点采用相同尺度。
5. **双判与仲裁。** 从各层随机抽取事先约定的一部分点由两人独立判读。保留两份原判，报告双判数、一致数及分歧类型。分歧交第三人结合证据复核；仍无定论则保留未知。用于指导改图的点记为修订点，最终验收使用未向制图人员展示的保留样本，或重新独立抽样。

## 4　统计精度、面积与岸线误差

**确定统计分母。** 面积统计在等面积投影下进行，或逐像元计算地面面积。简单分层随机抽样中，第 h 层有 Nₕ 个像元、抽取 nₕ 个，每点代表 Nₕ/nₕ 个像元；按面积统计时再乘该点对应的像元面积。按设计权重汇总 TP（正确报水）、FP（误报水）、FN（漏报水）、TN（正确判干）。完整独立参考图覆盖全域时，可直接在共同有效域计数。水体与新增淹没各用一张混淆矩阵。[Olofsson 等，遥感分类精度与面积估计](https://doi.org/10.1016/j.rse.2014.02.015)

| 要回答的问题 | 报告指标 | 解释 |
| --- | --- | --- |
| 报出的水有多少可信？有多少真水漏掉？ | Precision = TP/(TP+FP)，Recall = TP/(TP+FN) | 误报比例为 1−Precision，漏报比例为 1−Recall。分母为零时填“不适用”，并注明有无参考水体、是否有预测水体 |
| 同一范围内各版本差多少？ | F1 = 2TP/(2TP+FP+FN)，IoU = TP/(TP+FP+FN) | 同时报 Precision、Recall、纳入面积和各景差异。跨事件比较应列出水体占比和有效覆盖率。[洪水图验证策略研究](https://doi.org/10.1016/j.rse.2024.114439) |
| 面积偏了多少？ | 图上量算面积、抽样校正面积、二者差值（km²） | 当混淆矩阵各项均以地面面积计，校正面积估计为 TP+FN。注明统计时刻及空间范围 |
| 岸线往哪边偏？ | 参考岸线内侧漏报率、外侧误报率；有可靠位置参考时，追加横断线有符号偏移中位数、绝对偏移第 90 百分位（m） | 以参考岸线建立内外缓冲，写明宽度。横断线向陆扩张记正、向水收缩记负。整段消失或没有匹配岸线时另报缺失段数及长度，避免只统计成功匹配段 |

**抽样不确定性。** 对正式报告中的抽样精度、校正面积给出与抽样设计一致的 95% 置信区间，注明方法、各层有效样本数及分母。层内简单随机抽样可用分层设计方差或按层重采样估计；按河段、场景成组抽样时按对应一级抽样单元估计。区间反映抽样波动，另列时差、错位、云遮和判读分歧。某层样本太少、方差无法估计时，应注明，不能填零。

**难判点的处理。** 逐层报告未核验和无法判读数量、占比及原因，保留原点位。先补证或仲裁；仍有未知时，只报告已有证据支持的范围。若要报告全域估计，应说明缺失处理假设及其影响。缺少依据时，全域精度记为“待核”，不把难判点删掉后照报全域分数。

## 5　问题处置与签发

| 签发结论 | 适用条件 | 后续动作 |
| --- | --- | --- |
| 退回修订 | 日期或产品类型错误、未覆盖区被计为非水体、系统性错位、关键区域已确认整片漏绘，或统计重复计面积并影响交付结论 | 标注位置和影响，修订后生成新版本；复核受影响区域及所有引用它的汇总图表 |
| 快报可发，精度待核 | 覆盖、几何和文件快查已完成；独立证据或抽样尚不足；已知局限及重点区域状态已随图标明 | 标注过境时刻、有效覆盖、未知区和复核人，后续补发正式核验结论 |
| 正式核验通过 | 完成约定检查，指标满足事先约定的判据，关键缺陷已复核关闭 | 签发对应版本，保存抽样底表、判读证据、统计报告和问题处置记录 |
| 待补证／未达标 | 证据不足、无事先约定的门槛，或指标未达到门槛 | 区分“缺证据”和“有证据表明不达标”，分别安排补证或返工，不以放宽阈值追认通过 |

签发人应能从结论追溯到成果版本、核验范围及责任人。已经发出的图件发生实质修订时，在新版中注明变更区域、原因及受影响的面积或重点目标。

## 6　知识库和 Agent 的使用边界

知识库条目应注明来源、版本、适用传感器或场景。历史案例保留影像编号、日期、问题位置、独立参考及人工裁定；未经裁定的案例标为“疑似”。Agent 可检索案例、生成局部对照图、调用 GIS 工具量算掩膜重叠面积、解释处理步骤，并列出缺少的证据。每条意见关联到景号、点或面编号、工具结果和引用条目。

**生产排查可先看 Agent 意见，正式抽验应先完成人工盲判。** Agent 意见单列，人工参考字段由核验人填写。例：某库湾初提为水、最终被删，且删除范围与地形掩膜重合，可以确认“删除发生在地形处理环节”；判断该处实际是否有水，还要对照同期证据。机器意见和人工确认的事实应分别存档。使用已判案例检验 Agent 时，应留出未入库的案例并记录漏报、误报和无证据却给出确定判断的次数。

## 附注　与现有仓库的对应关系

阈值流程可生成水体内部、预测岸线带及其余非水体三层核验点和疑似区域。核验窗口使用 `1` 水体、`0` 非水体、`-1` 无法确定、空值未判读。现有统计脚本在指定范围全部点已有确定标签后输出加权精度点估计；预测岸线带得分用于描述附近分类表现。正式报告若要求参考岸线偏移、95% 区间、双人仲裁或新增淹没判读，应另行记录或计算。无标签模型推理输出的 `quality.json` 可用于逐景快查。[分层抽样](../src/thres_segmentation/quality_review.py) · [人工核验窗口](../src/validate_pts/README.md) · [加权统计](../scripts/threshold/evaluate_threshold_review.py) · [参考岸线缓冲评价](s1_samples/buffer_point_quality_metrics.md) · [整景模型推理](../src/supervised/predict.py)
