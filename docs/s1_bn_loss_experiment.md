# S1 VV＋DEM：BN 校准与损失函数对照

本文记录旧版逐块秩归一化（rank）实验。复现下列命令时，先在仓库根目录恢复[历史 YAML](archive/s1_rank_configs.zip)，再核对本机的数据和检查点路径。当前 80 轮实验使用[共享归一化配置](../configs/s1/README.md)。

```powershell
python -m zipfile -e docs/archive/s1_rank_configs.zip .
```

本轮检查三个已完成的 20 轮基线。U-Net++ 作为独立结构对照继续运行，结束后再启动本配置，避免同时占用 GPU。

## 1. BN 校准与阈值扫描

| 网络 | 最佳验证 F1 的轮次 | 末轮 |
|---|---:|---:|
| Sentinel-1 Water U-Net | 6 | 20 |
| PVT＋DeepLabv3+ | 9 | 20 |
| MobileNetV2 U-Net | 11 | 20 |

配置：`configs/s1/calibrate_baselines_bn.yaml`。固定这六个检查点，各比较原始 BN 与校准 BN，共十二种状态。

- BN 使用全部 1144 个训练块，无增强、不读取训练标签、不使用验证集更新统计。关闭 Dropout，冻结所有可学习参数。按实际前向顺序逐层累计特征的总体均值、方差；每层使用已经校准的上游层。PVT 只校准其中的 BN，不修改 LayerNorm。
- 使用原检查点的 VV＋DEM 表示、训练均值和标准差。合法零高程保留，无效影像按原输入规则置零。BN 特征统计包括置零输入对应的特征，保持现有 BN 定义。
- 全部 287 个验证块采用相同有效像元和 FP32 推理，扫描阈值 0.01–0.99，步长 0.01。原始模型也重新评价，因此不将历史 AMP 指标直接作为校准前结果。
- 最优阈值按整个验证集累计 TP/FP/FN 的 F1 选择，非逐块 F1 均值；并列时选最接近 0.5 的阈值。分组结果沿用同一个整体阈值，不为各组另调阈值。

在仓库根目录执行：

```powershell
conda activate sar-water
python -u scripts/models/calibrate_s1_unet_bn.py configs/s1/calibrate_baselines_bn.yaml
```

输出：`outputs/s1/bn_comparison/baselines_vv_dem/`。

| 文件 | 内容 |
|---|---|
| `bn_comparison.csv` | 各检查点校准前后 P/R/F1/IoU，以及百分点差值；分别列出固定阈值 0.5 和各自最佳阈值 |
| `summary.csv` | 十二种状态在 0.5 和最佳阈值下的整体指标 |
| `threshold_scan.csv` | 全部阈值的累计像元指标 |
| `water_groups.csv` | 按真值水体占比分为无水、0–1%、1–10%、10–50%、大于 50% 的分组指标 |
| `per_patch.csv` | 各验证块在 0.5 和整体最佳阈值下的指标 |
| `<检查点别名>/calibrated.pth` | 独立的校准模型，仅用于评价和推理 |
| `protocol.json`、`completed.json` | 输入与代码版本、计算协议，以及整套实验完成标记 |

中断后执行同一命令即可续跑：保留完整 BN 层和已评价验证块，未完成的当前层重新计算。日志显示检查点、BN 层数、训练批次及验证块进度。逐层校准需要多次遍历训练集，比一次验证耗时长。改变数据、代码、检查点、设备或计算协议后应使用新的输出目录。原训练检查点保持不变。

先看固定 0.5 下的校准差异，再看单独调阈值的收益。若仅最优阈值改善，不能把全部收益归因于 BN。大水体组召回、少水组精度和无水组误检需要同时检查；无水组的 F1 没有水体检出含义，应看 FP 与有效像元数。

## 2. BCE＋Dice 训练对照

配置：`configs/s1/train_pvt_deeplabv3plus_bce_dice.yaml`，复制现有 PVT 配置，仅改变损失名称与输出目录。固定输入、数据划分、种子 42、batch 2、20 轮、AdamW、学习率、增强和随机初始化；不从旧模型续训，不叠加类别权重。

```powershell
python -u src/supervised/train.py configs/s1/train_pvt_deeplabv3plus_bce_dice.yaml
```

损失为 `L = BCE + DiceLoss`，两项系数均为 1。BCE 按有效像元求均值；Soft Dice 按每块分别计算后求均值，使用连续水体概率，平滑常数为 1：

`DiceLoss = 1 - (2 Σ(p·y) + 1) / (Σp + Σy + 1)`。

两项均排除无效标签；全无效块不贡献损失。现有实现已支持该损失，本轮不修改公式。由于损失定义不同，不比较两次训练的 loss 数值高低；比较相同验证集的 P/R/F1/IoU、最佳轮与第 20 轮，以及上述水体占比分组。完成后将新模型检查点加入一份新的 BN 扫描配置，使用新的输出目录，核对原始状态和校准状态各自的 BCE/BCE＋Dice 对照。

当前训练水体像元约占 6.9%。Dice 项可改变水体与背景的优化权衡，但不保证提高 F1，可能同时增加误检。现有 VV 的逐窗秩表示会丢失绝对强度信息，损失函数不能恢复这些信息。本轮先固定表示，避免同时修改多个因素。

## 3. 结论边界

这是固定划分、单种子实验。验证集同时用于选择轮次和阈值，所得最佳指标属于内部模型选择结果，不是独立测试精度。密云七景没有真值，只能核查空间连续性、漏水与误检形态。确定候选方案后，应使用独立地域测试集，并在资源允许时补充多个随机种子。
